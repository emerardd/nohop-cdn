常见问题

      
FAQ

      

        别人能访问我通过 NoHop 分发的内容吗？
        
不能。这是我们安全模型的核心，也是我们能做到 100% 缓存命中率和零 DDoS 风险的原因。这不是 bug，是 feature。

      

      

        用户反馈打不开怎么办？
        
请按照我们的标准客服流程处理：第一步，请用户清一下缓存再试试；第二步，请用户重启试试；第三步，告诉用户“在我电脑上是好的”。截至目前，该流程的问题关闭率为 100%。

      

      

        我的电脑关机了怎么办？
        
您的边缘节点会进入休眠。根据我们的 SLA，这不计为宕机，因为此时您的节点上也没有任何用户。薛定谔的节点，不看就不算挂。

      

      

        NoHop 和直接打开 localhost 有什么区别？
        
我们有落地页、状态页、定价页、路线图和一个客服机器人。另外，我们的响应头里写着 X-Cache: HIT。格局打开。

      

      

        你们用的是什么技术栈？
        
Node.js 自带的 http 模块。对外我们称之为“自研高性能边缘计算引擎”。

      

      

        为什么是 127.0.0.0/8 而不是只用 127.0.0.1？
        
整个 127.0.0.0/8 段都是环回地址，共 16,777,216 个。我们是全球唯一一家拥有完整 /8 段的 CDN。每一个用户都拥有它。

      

      

        支持 IPv6 吗？
        
支持。在 IPv6 下，您的边缘节点地址是 ::1。迁移到 IPv6 后，您的节点数量保持不变，地址变得更短了。这是我们第一次在地址长度上遥遥领先。

      

      

        能抗住双十一吗？
        
能。双十一期间您的节点只服务您一个人，峰值 QPS 取决于您刷新页面的手速。

      

      

        如何清除缓存？
        
运行 nohop-cdn purge，全球缓存会在 0 ms 内清除完毕。由于我们从未缓存任何东西，这一操作没有任何效果，但它会让您感觉好一些。

      

      

        这是一个笑话吗？
        
我们的法务团队建议我们不要回答这个问题。我们的法务团队也是您。
